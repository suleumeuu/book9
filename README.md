# C++ машинаға бағытталған бағдарламалау — электрондық оқулық

## Іске қосу
1. ZIP архивін ашыңыз.
2. `index.html` файлын браузерде ашып тексеріңіз.
3. GitHub-та жаңа repository құрыңыз.
4. Архив ішіндегі барлық файлдар мен `assets` бумасын repository түбіріне жүктеңіз.
5. Repository → Settings → Pages → Build and deployment → Deploy from a branch таңдаңыз.
6. Branch ретінде `main`, folder ретінде `/ (root)` таңдап Save басыңыз.

GitHub Pages жариялағаннан кейін сайттың сілтемесі әдетте `https://USERNAME.github.io/REPOSITORY/` болады.

Сайт статикалық HTML/CSS/JS негізінде жасалған, сондықтан сервер не қосымша орнату қажет емес.
